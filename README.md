# FEPNN-Contraction-Certified-Neural-Residual-Framework
## Description: 

A contraction-certified neural residual framework for solving weighted-composition functional equations with endpoint constraints, fixed-point stability analysis, and computable a posteriori error bounds. The repository supports the numerical implementation of the FEPNN method, including residual minimization, Picard-based reference solutions, and accuracy assessment for contractive functional equation models.
